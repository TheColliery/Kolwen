# Kolwen

**The language model family fired by [TheColliery](https://github.com/TheColliery).**

Kolwen carries TheColliery's engineering discipline — measured-not-trusted, honesty over polish, safety rails by construction — into a model you can actually run.

## The family

| model | seat |
|---|---|
| **Kolwen** | the free model — open weights, run it yourself |
| **Kolwen Peat** | smallest of the fired line |
| **Kolwen Lignite** | the workhorse |
| **Kolwen Anthracite** | the top — highest-grade coal, hottest and cleanest burn |

The names follow the real coalification sequence: peat → lignite → anthracite.
