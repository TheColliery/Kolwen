# Kolwen

**The language model family fired by [TheColliery](https://github.com/TheColliery).**

Kolwen carries TheColliery's engineering discipline—measured-not-trusted, honesty over polish, safety rails by construction—into models meant to be run by their users. None has shipped yet.

## The family

**None of these models has shipped.** The table names the seat each is meant to fill; nothing is
downloadable yet, as the Status section says.

| model | intended seat |
|---|---|
| **Kolwen** | the free model—open weights, run it yourself |
| **Kolwen Peat** | smallest of the fired line |
| **Kolwen Lignite** | the workhorse |
| **Kolwen Anthracite** | the top—highest-grade coal, hottest and cleanest burn |

The names follow the coalification series: peat → lignite → (sub-bituminous) → bituminous →
(semi-)anthracite. Kolwen names four ranks; the bracketed grades are seams, not tiers. Bituminous
is a named rank with no model behind it yet—reserved, not shipped.
