# Owner rulings that bind Kolwen

> Part of Kolwen's control-family set. This file is an **index that only points**. It decides
> nothing. Written and kept by the Kolwen department head, through its belt: the doc-writer
> drafts a row, the reviewer inspects it, the head ships it. The owner's sheet stays the source of
> every signature. Each row names its card id, and that card on the sheet is the record.
> What `AR-n` means is in [the index](README.md); this file uses card ids, which are references
> and never appear in a commit subject.

## How to read the rows

- **Signed** means the owner signed the card. A row marked "signed; the text is not yet published"
  binds a notice that is still dark. Such a row quotes no value the notice holds.
- **Ruling held privately** means the ruling's text is private (an unpublished price, date or
  plan). The row carries the id only, and the return that wrote it names every such row.
- **Open** means waiting on the lawyer or the owner. An open value is never presented as settled.
- **Provisional** means a legal seat's reading. Nothing here is settled law: the lawyer has not
  signed any of it.
