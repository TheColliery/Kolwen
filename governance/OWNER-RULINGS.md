# Owner rulings that bind Kolwen

> Part of Kolwen's control-family set. This file is an index that only points. It decides nothing.
> It is kept by Kolwen's maintainer. The owner's signed record is the source of every
> signature, and each row names its signed record, or the project document that carries the ruling. The file names only signed rulings that shape
> a public surface, and each row says where the public can see it.

## How to read the rows

- **Signed** means the owner signed the record. A row marked "signed; the text is not yet published"
  binds a notice not yet published. Such a row quotes no value the notice holds.
- **Open** means waiting on the lawyer or the owner. An open value is never presented as settled.
- **Provisional** means a preliminary legal reading. Nothing here is settled law: no lawyer has
  signed any of it.
