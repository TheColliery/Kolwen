Accessibility

This page is Kolwen's accessibility statement for the website at kolwen.com. It is dated 1 November 2026.

What this site is

Kolwen's website describes a chatbot product that is still in development. No product ships yet, and the home page says so. The site is a set of static pages in English and Thai, which a visitor reads in a browser.

Our commitment

Kolwen aims to make the website usable by people with disabilities, and to fix a problem that a visitor reports.

The standard we aim for

Kolwen's own target is WCAG 2.2 level AA. It is a target Kolwen set for itself. It is not a legal test, and this statement does not claim that the site meets it.

What is checked on every change

The repository runs these checks in its continuous integration on each pull request and each push to main, and a failed check fails the change. A headless browser checks every page, in English and Thai: text reflows at 320 CSS pixels wide without sideways scrolling; text at 200 percent is not cut off; the browser reports no content-security-policy violation; the language switch sets the page's language. On the reading pages, text and background meet a contrast of 4.5 to 1 (3 to 1 for large text) in both the light and the dark colour scheme, the line height is at least 1.5 times the font size, and the line length of English text is measured against 80 characters. The source checks confirm that the home page declares English as its language, and that the layout uses relative type sizes and a viewport setting that does not block zoom.

Known limits

The checks above cover only what they measure. They do not test every criterion of WCAG 2.2. In particular, no check reads the keyboard focus order or whether focus is visible; no check reads the names and roles of controls with a screen reader; the contrast and line-height checks cover the reading pages, not the default pages, whose background gradient is not read; the line-length check does not apply to Thai text; and the pages have not been checked with script switched off. The repository records no manual audit and no test with assistive technology by people.

What you need

The site needs a current browser. It needs no plug-in, and no account or sign-in to read a page. Whether a page reads with script switched off is not checked.

Report a problem

If a page is hard for you to use, write to info@kolwen.com with the address of the page and what got in your way. We read every report and answer it. We do not promise a time for the answer.

Date of this statement

1 November 2026.

การเข้าถึงได้

หน้านี้คือคำแถลงการเข้าถึงได้ของเว็บไซต์ kolwen.com ลงวันที่ 1 พฤศจิกายน 2569

เว็บไซต์นี้คืออะไร

เว็บไซต์ของ Kolwen อธิบายผลิตภัณฑ์แชตบอตที่ยังอยู่ระหว่างการพัฒนา ยังไม่มีผลิตภัณฑ์ใดเปิดให้ใช้งาน และหน้าแรกของเว็บไซต์บอกเช่นนี้ เว็บไซต์เป็นชุดหน้าคงที่ทั้งภาษาอังกฤษและภาษาไทย ผู้เยี่ยมชมอ่านหน้าเหล่านี้ผ่านเบราว์เซอร์

คำมั่นของเรา

Kolwen ตั้งใจให้เว็บไซต์ใช้งานได้สำหรับผู้มีความพิการ และแก้ไขปัญหาที่ผู้เยี่ยมชมแจ้งมา

มาตรฐานที่เราตั้งเป้าหมาย

เป้าหมายของ Kolwen คือ WCAG 2.2 ระดับ AA เป็นเป้าหมายที่ Kolwen กำหนดเอง ไม่ใช่เกณฑ์ทางกฎหมาย และคำแถลงนี้ไม่ได้อ้างว่าเว็บไซต์ผ่านเป้าหมายนี้แล้ว

สิ่งที่ตรวจทุกครั้งที่มีการเปลี่ยนแปลง

ที่เก็บโค้ดรันการตรวจเหล่านี้ในระบบตรวจสอบต่อเนื่องทุกครั้งที่มีคำขอรวมโค้ดและทุกครั้งที่ส่งการเปลี่ยนแปลงเข้า main และการตรวจที่ไม่ผ่านทำให้การเปลี่ยนแปลงล้มเหลว เบราว์เซอร์แบบไม่แสดงผลตรวจทุกหน้าทั้งภาษาอังกฤษและภาษาไทย ได้แก่ ข้อความจัดเรียงใหม่ได้ที่ความกว้าง 320 พิกเซลโดยไม่เลื่อนด้านข้าง ข้อความที่ซูมเป็น 200 เปอร์เซ็นต์ไม่ถูกตัด เบราว์เซอร์ไม่รายงานการละเมิดนโยบายความปลอดภัยของเนื้อหา และปุ่มสลับภาษาตั้งค่าภาษาของหน้า ในหน้าอ่าน สีข้อความกับพื้นหลังมีความคมชัดอย่างน้อย 4.5 ต่อ 1 (3 ต่อ 1 สำหรับข้อความขนาดใหญ่) ทั้งโหมดสว่างและโหมดมืด ความสูงบรรทัดอย่างน้อย 1.5 เท่าของขนาดตัวอักษร และความยาวบรรทัดของข้อความภาษาอังกฤษถูกวัดเทียบกับ 80 ตัวอักษร การตรวจต้นทางยืนยันว่าหน้าหลักประกาศภาษาอังกฤษ และการจัดวางใช้ขนาดตัวอักษรแบบสัมพัทธ์กับการตั้งค่า viewport ที่ไม่บล็อกการซูม

ข้อจำกัดที่ทราบ

การตรวจข้างต้นครอบคลุมเฉพาะสิ่งที่วัดเท่านั้น ไม่ได้ทดสอบทุกเกณฑ์ของ WCAG 2.2 โดยเฉพาะ ไม่มีการตรวจลำดับการโฟกัสด้วยคีย์บอร์ดหรือการมองเห็นโฟกัส ไม่มีการตรวจชื่อและบทบาทของปุ่มควบคุมด้วยโปรแกรมอ่านหน้าจอ การตรวจความคมชัดและความสูงบรรทัดครอบคลุมหน้าอ่าน ไม่ครอบคลุมหน้าปกติซึ่งไม่อ่านพื้นหลังแบบไล่สี การตรวจความยาวบรรทัดไม่ใช้กับข้อความภาษาไทย และหน้าเว็บยังไม่ได้ทดสอบโดยปิดสคริปต์ ที่เก็บโค้ดไม่มีบันทึกการตรวจโดยคน และไม่มีการทดสอบโดยผู้ที่ใช้เทคโนโลยีช่วยเหลือ

สิ่งที่ต้องมี

เว็บไซต์ต้องใช้เบราว์เซอร์ที่ทันสมัย ไม่ต้องใช้ปลั๊กอิน และไม่ต้องมีบัญชีหรือการเข้าสู่ระบบเพื่ออ่านหน้าใด ยังไม่ได้ตรวจว่าหน้าอ่านได้เมื่อปิดสคริปต์

แจ้งปัญหา

หากหน้าใดใช้ยาก โปรดเขียนถึง info@kolwen.com พร้อมที่อยู่ของหน้านั้นและสิ่งที่ขัดขวาง Kolwen อ่านทุกรายงานและตอบกลับ ไม่ได้ให้เวลาตอบที่แน่นอน
